# 나만의 만화 번역기

만화·웹툰 이미지를 올리면 말풍선을 찾아 번역하고, 원래 글자를 지운 자리에 번역문을 넣어 주는 개인용 웹 앱입니다. 내 컴퓨터에서 실행하고 내 API 키로만 동작합니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
cp .env.example .env      # 그리고 .env 에 ANTHROPIC_API_KEY 입력
npm start
```

브라우저에서 <http://localhost:3000> 을 엽니다.

API 키 없이 화면만 먼저 보고 싶다면 `npm run mock` (가짜 번역 결과가 나옵니다).

## 기능

- 여러 장 한꺼번에 올리기 (클릭 · 끌어다 놓기 · Ctrl+V 붙여넣기)
- 세로로 긴 웹툰은 컷 사이 빈 곳을 찾아 자동으로 나눠 번역
- 번역문 직접 수정, 상자 이동·크기 조절·추가·삭제, 글자 크기 지정
- "원본 보기"를 누르고 있는 동안 원본과 비교
- 번역 언어 12종, 글꼴 3종, 효과음 번역 켜기/끄기
- "이름·용어 메모"에 등장인물 이름이나 말투를 적어 두면 모든 페이지에 적용
- PNG 로 한 장씩 또는 전체 다운로드 (원본 해상도)

## 폰에서 쓰기

1. `.env` 에 `APP_PASSWORD=원하는비밀번호` 를 넣고 `npm start` 를 다시 실행합니다.
2. 터미널에 `같은 Wi-Fi 의 폰에서 접속 → http://192.168.x.x:3000` 주소가 나옵니다.
3. PC 와 같은 Wi-Fi 에 연결된 폰 브라우저에서 그 주소를 열고 비밀번호를 입력합니다.

- 브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.
- 폰에서는 다운로드 버튼이 공유 창을 열어 사진 앱에 바로 저장할 수 있습니다.
- 그림 위 글자는 한 번 눌러 선택한 뒤에 끌어서 옮깁니다.
- 접속이 안 되면 PC 방화벽에서 Node.js(포트 3000) 허용 여부를 확인하세요.
- 집 밖에서도 쓰려면 PC 와 폰에 [Tailscale](https://tailscale.com) 을 설치하고 PC 의 Tailscale 주소로 접속하는 방법이 가장 간단합니다. PC 는 켜져 있어야 합니다.

## 나만 쓰기

- 비밀번호를 설정하지 않으면 이 컴퓨터에서만 접속됩니다 (`127.0.0.1`).
- 비밀번호를 설정하면 같은 네트워크의 다른 기기에서도 접속할 수 있고, 접속할 때 비밀번호를 묻습니다. 비밀번호 없이 외부 주소로는 실행되지 않습니다.
- 이미지는 번역을 위해 Anthropic API 로만 전송되고, 서버에는 저장하지 않습니다.

## 설정 (.env)

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | – | Anthropic API 키 |
| `MODEL` | `claude-opus-5-5` | 더 싸게 쓰려면 `claude-sonnet-5-5`, `claude-haiku-5-5` |
| `HOST` / `PORT` | 자동 / `3000` | 접속 주소. 비밀번호가 있으면 `0.0.0.0`, 없으면 `127.0.0.1` |
| `APP_PASSWORD` | 없음 | 설정하면 폰 등 다른 기기에서 접속할 수 있고, 접속할 때 비밀번호를 묻습니다 |

## 구조

- `server.js` – 정적 파일 제공, 비밀번호 확인, Claude 에 이미지 전송 후 글자 영역과 번역문(JSON) 받기
- `public/app.js` – 이미지 축소·분할, 캔버스에 번역문 그리기, 편집기
